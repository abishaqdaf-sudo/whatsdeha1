# Whatsdeha — Android Studio project

Generated by Toolspea Android WebView App Builder
(https://toolspea.com/android-webview-app-builder).

This is **source code**, not a compiled app. Toolspea does not build APK or AAB
files, so nothing in this ZIP is a binary you could sideload directly.

## Opening the project

1. Unzip the archive.
2. Open Android Studio → **Open** → select the unzipped folder.
3. Android Studio will offer to generate the Gradle wrapper and download the
   Android Gradle Plugin, Kotlin and AndroidX dependencies. Accept.
4. Press **Run** with a device or emulator attached.

If you prefer the command line and already have Gradle installed:

    gradle wrapper
    ./gradlew assembleDebug

## What the app does

* Loads `https://whatsdeha.blogspot.com/` in a full-screen WebView with no toolbar and no address bar.
* JavaScript enabled, DOM storage enabled, cookies enabled.
* Pull to refresh enabled. Slim top loading bar enabled.
* Back button: walks WebView history, then asks before exiting.
* External links: opened in the system browser.
* Hosts treated as internal: whatsdeha.blogspot.com.
* Failed main-frame loads show a branded offline screen with a Retry button
  instead of the raw WebView error page.
* SSL errors are **not** bypassed. `onReceivedSslError` is intentionally not
  overridden, so invalid certificates cancel the load.
* No JavaScript bridge (`addJavascriptInterface`) is registered, so the web page
  cannot reach Android APIs.

## Permissions requested

* **Internet** (`android.permission.INTERNET`) — Required to load the website.
* **Network state** (`android.permission.ACCESS_NETWORK_STATE`) — Detects when the device is offline so the app can show its own error screen.

## Network security

Cleartext HTTP is blocked (the Android default from API 28). If your site is
served over plain HTTP the page will fail to load — use HTTPS.

## Publishing

Google Play does not accept every WebView wrapper. Store policy requires apps to
provide value beyond a repackaged website, so a thin wrapper around a site you do
not own is likely to be rejected. Make sure you own or are licensed to publish
the content, and add real app value where you can.

## Changing the URL later

Edit `startUrl` in `app/src/main/java/com/blogspot/whatsdeha/app/MainActivity.kt`.
